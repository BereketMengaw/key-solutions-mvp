# Key Solutions — Restaurant ERP (MVP demo)

Waiter app, kitchen screen and owner dashboard for restaurants in Addis Ababa.

- `mobile/` — Expo app for waiters (phone) and cooks (tablet)
- `web/` — Next.js dashboard for owners and managers
- `supabase/` — database, auth, stock logic
- `design/` — design tokens and screen specs
- `shared/` — types and constants used by every app
